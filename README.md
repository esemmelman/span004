# Spanish Conjugations

A browser-based Spanish practice app with Study, Test, vocabulary, and Ser/Estar usage rules.

Live site: https://esemmelman.github.io/span004/

## Run locally

Open `index.html` in a browser. On Windows with Node.js installed, you can also double-click `Start Spanish.cmd` to serve it at http://localhost:8000.

## Publish updates

GitHub Pages serves the root of the `main` branch. Commit and push changes to `main`; GitHub automatically rebuilds the site. No build step, API keys, or backend is needed.
